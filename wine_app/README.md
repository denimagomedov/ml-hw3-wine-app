# Винная подборка

Модель оценивает вероятность того, что вино получит экспертную оценку 7 или выше. Порог в боковой панели применяется к отдельному вину, тестовым метрикам и загруженному CSV.

## Запуск

Проверено на Python 3.12.10. Из папки HW3 с готовой средой запустите:

```bash
.venv/bin/python -m streamlit run wine_app/app.py
```

Если у вас только папка приложения, откройте её и выполните:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Файлы `model.joblib`, `config.json` и `test.csv` должны лежать рядом с `app.py`. Их создаёт ячейка сохранения в ноутбуке. Для пакетного прогноза загрузите CSV с 12 признаками модели. Столбец `target` для прогноза не нужен.

## Кэширование

`st.cache_resource` хранит один объект обученного пайплайна и отдаёт его всем запускам приложения. `st.cache_data` сохраняет таблицу и массив вероятностей, а при обращении отдаёт их копии. Ползунок меняет только сравнение тестовых вероятностей с порогом. При вызове `joblib.load` без кэширования Streamlit будет читать и распаковывать модель при каждом перезапуске скрипта.
